# Structure

The five protocol folders own public inbound.json templates. runtime/configuration.py renders one Xray and one sing-box configuration from the independent private owner. runtime/supervisor.py owns two child processes inside the single Compose vpn service. tools/ owns preparation, private backups, explicit Linux cutover and authorized native client automation. The testing Skill owns synthetic contracts and real acceptance boundaries. Private inputs and output reports stay in private/ or deployment-native owners, never the source map.
